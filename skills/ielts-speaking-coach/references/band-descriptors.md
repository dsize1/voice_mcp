# 雅思口语评分描述与可测量代理指标

> 用途：定级、复评、判断"这算 6 还是 7"。
> 关键原则：**描述是主观的，指标是客观的**。本文件把描述映射到我们能测的量，但只能用于**内部参考**，
> 不要对用户承诺"你现在是 6.5"。

## 1. Pronunciation（发音）官方描述要点

| Band | 描述关键词（意译） |
|---|---|
| 5 | 有可理解度问题，母语口音影响明显，部分音素错误频繁 |
| 6 | 使用一定范围的发音特征但控制不稳；总体可理解，个别单词/音素错误会降低清晰度 |
| 7 | 具备 6 的全部正面特征 + 8 的部分特征；**能被轻松理解**，母语口音影响很小 |
| 8 | 使用较广范围的发音特征，灵活使用且仅偶有失误；全程易懂 |
| 9 | 全范围精确、细腻地使用发音特征，毫不费力 |

**6→7 的分水岭**：不是"音素更准"，而是
① 错误**不再影响理解** ② 有**重音与语调的变化**（不是一字一顿的平调）③ 连读/弱读开始自然出现。

## 2. Fluency & Coherence（流利与连贯）官方描述要点

| Band | 描述关键词 |
|---|---|
| 5 | 通常维持语流但需靠重复/放慢；连接词单一 |
| 6 | 愿意长篇表达但连贯性下降；有重复、自我修正；连接词使用不总是恰当 |
| 7 | 能不太费力地长篇表达；偶有重复/自我修正；**灵活使用连接词与话语标记** |
| 8 | 流利，偶有停顿但都发生在内容而非找词上 |

## 3. 可测量代理指标（`assess` 的输出）

| 指标 | 6 分附近 | 7 分附近 | 备注 |
|---|---|---|---|
| `accuracy`（跟读同一参考句） | 0.75–0.88 | ≥ 0.90 | 只适合同句纵向对比，不适合跨句比较 |
| `issues` 中 P0 类（omitted / likely_pronunciation） | 2–4 处/长句 | ≤ 1 处 | 最关键指标 |
| `speech_rate`（朗读已知文本） | 90–130 wpm | 130–170 wpm | 独白会低 15–25%，别混用 |
| `articulation_rate` | 130–180 | 180–240 | 反映"说话本身"的速度 |
| `speech_ratio`（发声/总时长） | 0.55–0.7 | ≥ 0.75 | 低 = 停顿多或录音留白多 |
| `pause_count`（每 30 s） | 3–5 | ≤ 2 | 且停顿应落在意群边界 |
| `pause_longest` | 0.8–1.5 s | < 0.8 s | > 2 s 是很明显的卡顿 |
| `filler_rate`（每百词） | 3–8 | ≤ 2 | um/uh/嗯 |
| `repetitions`（每 30 s） | 2–4 | ≤ 1 | 自我修正 |
| `word_boundary_breaks`（每句） | 1–3 | 0–1 | 连读是否自然 |
| `longest_run_words` | 5–9 | 12+ | 一口气能说多长 |

> ⚠️ 这些区间是**工程经验值**，用于同一用户纵向对比。跨用户比较会失真（性别、年龄、麦克风、录音机采样率都影响）。
> `band_limited=true`（16 kHz 源）时，`accuracy` 会系统性偏低 0.03–0.08，历史对比要同一通道比。

## 4. 定级流程（用第 2 节的基线诊断数据）

打分不是算术平均，按**短板优先**：

```
if P0 错误 ≥ 4 或 accuracy < 0.55           → 5.0
elif P0 错误 2–3 且 语速 < 90               → 5.0–5.5
elif P0 错误 1–2 且 停顿适中                → 5.5–6.0
elif P0 ≤ 1 且 speech_ratio ≥ 0.6 且 语速 ≥ 110 → 6.0–6.5
elif P0 ≈ 0 且 停顿落在意群 + 有升降调      → 6.5–7.0
else                                        → 7.0+
```

输出格式：

```json
{ "band_estimate": 6.0, "range": [5.5, 6.5], "confidence": "medium",
  "reason": "accuracy 0.86，但 P0 错误 3 处（词尾辅音为主）、语速 88 wpm、句末平调" }
```

`confidence`：`low`（少于 3 条素材）/ `medium`（3–8 条）/ `high`（≥ 10 条 + 一次 Part 2 独白）。

## 5. 什么情况下**不要**下调定级

- 用户紧张导致的一次性卡顿（看 `history` 是否有相同模式，单次不算）
- 更换素材（新话题词汇不熟，是词汇问题不是发音）
- 换录音通道（16k 录音机 vs 48k 麦克风，`band_limited` 差异）
- 录音环境噪声（`audio.silent_ratio` 或峰值异常时，先让用户重录）

## 6. 复评（每 5 次训练）

1. 一次 Part 2 长独白（1–2 分钟，无参考文本）→ 取 `speech_rate` / `pause_*` / `filler_rate` / `repetitions`
2. 两条跟读（一条旧素材、一条新素材）→ 取 `accuracy` / P0 错误数
3. 与 `history` 最近 3 次对比，只报告**变化趋势**：
   `语速 88 → 102 → 118 wpm；P0 错误 3 → 2 → 1；停顿 4 → 3 → 2`
4. 更新 `band_estimate` 与 `focus`（取 `error_stats` 里 count 最高的 1–2 项）
